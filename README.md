## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/yourusername/ExercismSolutions.git
cd ExercismSolutions
```

### Navigate to a Language Track

```bash
cd Java        # For Java solutions
# or
cd Python      # For Python solutions
# or
cd JavaScript  # For JavaScript solutions
```

### Run Tests

```bash
# Java
javac *.java
java -jar exercism.jar

# Python
python -m pytest

# JavaScript
npm test
```
